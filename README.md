程式功能：

1.顯示全部書籍：依序顯示書籍的編號、書名、作者、價格及借閱狀態，價格靠右對齊並加上千分位符號

2.新增書籍：輸入編號、書名、作者與價格，編號不可重複、欄位不可空白、價格須大於0的整數

3.查詢書籍：輸入書名進行搜尋，英文字母不分大小寫，列出符合條件的書籍

4.變更借閱狀態：輸入書籍編號切換借閱狀態

5.顯示最後3筆書籍與統計：以切片顯示最後3筆書籍，並計算書籍的總數、可借閱數、已借出數、金額合計與平均價格

6.匯出書籍資料：將目前的書籍資料寫入 output.json 檔案

7.離開系統：結束程式


執行方式：

開啟終端機，輸入python app.py 即可啟動程式
