
# 簡易書籍管理系統

命令列介面（CLI）書籍管理系統，支援書籍檢視、新增、關鍵字查詢、借閱狀態切換與統計匯出。

## 系統功能

1. **顯示全部書籍**：條列所有書籍資料，並以千分位對齊價格。
2. **新增書籍**：防呆驗證輸入欄位（編號不重複、書名/作者不可為空、價格須為正整數）。
3. **查詢書籍**：支援不分大小寫的書名關鍵字模糊搜尋。
4. **變更借閱狀態**：依書籍編號快速切換「可借閱」與「已借出」狀態。
5. **顯示最後 3 筆與統計**：以切片顯示末 3 筆，並即時統計總書數、借出數、合計與平均價格。
6. **匯出書籍資料**：將目前的書籍列表寫入 `output.json`（保留中文字且格式化縮排）。
7. **離開系統**：退出程式。
